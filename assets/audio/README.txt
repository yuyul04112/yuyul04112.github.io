에셋 가이드
==========

- sfx-train-start.mp3 : 기차 출발음
- sfx-zombie-groan.mp3 : 좀비 신음소리
- sfx-metal-screech.mp3 : 금속성 소음
- sfx-scream-distant.mp3 : 멀리서 들리는 비명
- sfx-footsteps-chase.mp3 : 추격 발소리
- sfx-helicopter-rescue.mp3 : 구조 헬기 소리

권장: MP3, 128kbps 이상, 30초 이내
